## IMPORTANT BEFORE PUBLISHING
1. The Impressum still needs the real full provider name/legal form and a serviceable postal address. Do not publish the placeholder version as final.
2. The Datenschutz page must be adapted to the real hosting and services used.
3. FormSubmit requires activation of the receiving email address after the first form submission. The form uses multipart/form-data and allows one PNG/JPG/PDF attachment. FormSubmit documents a 10 MB total file limit.
4. FormSubmit is an external provider. For a production business site, review its data protection terms or replace it with your own server-side mail endpoint.
5. The confirmation checkbox and timestamp are useful evidence inside the submitted email, but a static browser form cannot be made tamper-proof. For stronger proof, log agreements server-side with a signed terms/version record.
6. Steinwerk Bau has no verified live URL in the recovered M.HOLLY project files, so the portfolio does not invent one. Add the real URL when known.
7. Legal text on the website is a practical implementation draft, not a substitute for individual legal advice or formal AGB/Widerrufsbelehrung.
